## 실행

**터미널 없이** — 폴더 안의 `실행.bat`을 더블클릭하면 됩니다.

**터미널로** —

```bash
npm run live
```

터미널에 세 개의 주소가 뜹니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 진행자 (권장) | `http://localhost:3000/host?k=키` | 진행자 노트북 |
| 진행자 (인터넷) | `https://...trycloudflare.com/host?k=키` | 참고용 — 다른 컴퓨터에서 볼 때만 |
| 팀 참여 | `https://...trycloudflare.com/` | 팀 담당자 휴대폰 (QR) |

**진행자 화면은 `localhost` 주소로 여세요.** QR은 진행자 화면 위치와 상관없이 항상 알아서 인터넷 주소를 찾아 그려줍니다. localhost로 열면 와이파이·인터넷이 잠깐 끊기거나 터널이 죽어도 **진행자 화면은 멀쩡히 돌아갑니다** — 참가자 접속만 그 순간 막힐 뿐 진행은 그대로 할 수 있습니다.

## 컴퓨터를 계속 켜놔야 하나요?

**네.** 이건 클라우드 서비스가 아니라 그 노트북에서 도는 서버라서, 행사 내내 켜져 있어야 합니다. 절전 모드로 들어가지 않게 설정해 두세요. 터미널 창(또는 `실행.bat` 창)을 닫으면 서버가 멈추고 모든 접속이 끊깁니다.

주소가 바뀌는 경우는 두 가지입니다.
- 서버를 껐다 켜면 **무조건** 새 주소가 나옵니다.
- 서버는 켜져 있는데 인터넷 터널 주소만 죽는 경우가 가끔 있습니다(Cloudflare 무료 터널의 알려진 결함 — 아무 에러 표시 없이 그냥 안 열림). **서버가 45초마다 스스로 확인해서, 죽은 걸 발견하면 자동으로 새 주소를 만듭니다.** 참가자 QR은 진행자 화면이 자동으로 다시 맞춰주니 진행자가 따로 할 일은 없지만, **이미 화면을 찍어서 인쇄해 둔 QR이 있다면 그건 못 따라옵니다** — 그래서 화면에 뜨는 QR로 안내하는 걸 권장합니다.

**행사 시작 전 반드시 실제로 두 링크(진행자 localhost, 팀 참여 QR)를 열어서 접속되는지 확인**하세요. 리허설과 실전 사이에 시간이 비면 한 번 더 확인하는 게 안전합니다.

인터넷 없이 같은 와이파이만 쓸 때는 `npm start`로 실행하고, 터미널에 뜨는 `http://192.168.x.x:3000/` 주소를 씁니다.

## 진행 순서

1. **대기화면** — QR과 테이블 번호 현황이 뜹니다. 팀 담당자가 QR을 찍고 자기 테이블 번호를 누릅니다.
   - QR은 **진행자 화면을 연 주소**를 그대로 씁니다. 진행자 화면을 터널 주소로 열면 QR도 자동으로 맞춰지니 따로 손댈 일이 없습니다. (다른 주소를 쓰려면 화면의 주소칸에 넣고 «주소 적용»)
2. **퀴즈 시작** — 문제와 보기가 뜨고 곧바로 답변을 받습니다. 타이머는 없습니다. 팀은 마감 전까지 답을 바꿀 수 있고, 제출한 팀 원에는 노란 ✓ 가 붙습니다.
   - 접속하지 않은 팀은 기다리지 않습니다. 「제출 3 / 5팀」의 분모는 **실제로 들어온 팀** 수입니다.
   - 들어온 팀이 모두 답하면 버튼이 깜빡입니다. 아무도 답하지 않아도 그대로 넘어갈 수 있습니다 (기권 처리).
3. **정답 공개** — 누르는 **그 순간 답변이 마감**됩니다. 오른쪽에 정답·핵심 숫자·해설이 크게 뜨고, 왼쪽에 팀별 O/X가 나옵니다.
4. **다음 문제** — 반복.
5. **최종 순위** — 연습문제를 뺀 10문제 기준 팀별 누적 점수 순위.
6. **마무리 문구** — 순위 다음 페이지입니다.

진행은 **진행자가 직접 조작**합니다. 팀 화면은 진행자가 넘긴 상태를 따라갈 뿐이고, 팀은 답만 누릅니다.

조작 바 맨 왼쪽 **큰 버튼 하나**가 지금 단계에 맞게 이름이 바뀝니다. 그 버튼만 눌러도 처음부터 끝까지 진행됩니다.

- `⛶ 전체화면` — 상단 제목 줄을 감추고 화면을 넓게 씁니다. 아래 조작 바는 남아 있어서 계속 클릭할 수 있습니다. 끄려면 같은 버튼이나 `Esc`.
- `⋯ 더보기` — 대기화면·최종 순위·초기화 같은 가끔 쓰는 버튼을 폅니다.

## 단축키 (진행자 화면)

| 키 | 동작 |
|---|---|
| `Space` | 다음 단계 (정답 공개 → 다음 문제) |
| `←` `→` | 이전 / 다음 문제 |
| `F` | 전체화면 켜기 / 끄기 |
| `Esc` | 전체화면 끄기 |
| `H` | 아래 조작 바 통째로 숨기기 / 보이기 |

## 테이블 번호

화면에 보이는 번호는 테이블 배치도와 같습니다. 의제 번호 뒤에 테이블이 둘이면 `-1`, `-2`가 붙습니다.

| 번호 | 의제 | | 번호 | 의제 |
|---|---|---|---|---|
| `1-1` `1-2` | 1. 청년 | | `4-1` `4-2` | 4. 스쳐 |
| `2-1` `2-2` | 2. 사회 | | `5-1` `5-2` | 5. 기후 |
| `3` | 3. 농촌 | | `6` | 6. 자연 |

번호를 바꾸려면 `jeongeup-quiz-2026.json`의 `teams`에서 `label`만 고치세요. `no`는 내부 식별용이라 그대로 두셔야 답변과 점수가 유지됩니다.

## 점수

- 연습문제(P0)는 점수에 들어가지 않습니다. (화면에 그 문구는 띄우지 않습니다)
- 본문제 10개는 정답 1점.
- 동점이면 정답을 빨리 누른 팀이 앞섭니다. **공동 순위 없이 1위부터 10위까지 갈립니다.**

## 사고 대비

- 진행자가 새로고침하거나 인터넷이 끊겨도 답변과 점수는 서버에 남습니다 (`state.json`).
- 서버를 껐다 켜도 진행 상황이 복구됩니다. 처음부터 다시 하려면 `state.json`을 지우고 실행하세요.
- 팀 휴대폰은 자동 재접속됩니다. 화면이 멈추면 새로고침하면 됩니다 (팀 번호는 기억됩니다).
- 연결이 끊기면 진행자 화면 오른쪽 위에 빨간 **«연결 끊김»** 표시가 뜹니다. 전체화면 중에도 보입니다.
- 문제를 잘못 띄웠으면 **이 문제 답 초기화**로 그 문제만 다시 받을 수 있습니다.
- **전체 초기화**는 답변·점수뿐 아니라 접속한 팀 목록도 지웁니다. 리허설 끝나고 실전 전에 한 번 눌러 깨끗하게 시작하세요.
- 팀 담당자의 휴대폰 화면이 꺼지거나 다른 앱으로 갔다 와도 괜찮습니다. 같은 QR·주소로 다시 들어오면 그 팀의 답변과 점수가 그대로 남아 있습니다.
- 진행자 키(`k=`)를 모르면 아무도 진행자 화면에 못 들어옵니다.
