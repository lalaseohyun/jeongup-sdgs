## 진행 순서

1. **대기화면** — QR과 테이블 번호 현황이 뜹니다. 팀 담당자가 QR을 찍고 자기 테이블 번호를 누릅니다.
2. **퀴즈 시작** — 문제를 고르는 순간 곧바로 답변을 받습니다. 타이머는 없습니다. 팀은 마감 전까지 답을 바꿀 수 있고, 제출한 팀 원에는 ✓ 가 붙습니다.
   - 접속하지 않은 팀은 기다리지 않습니다. 들어온 팀이 모두 답하면 버튼이 깜빡입니다.
3. **정답 공개** — 누르는 **그 순간 답변이 마감**됩니다.
4. **다음 문제** — 반복.
5. **최종 순위** — 연습문제를 뺀 10문제 기준. 동점이면 정답을 빨리 누른 팀이 앞서고, 공동 순위는 없습니다.
6. **마무리 문구**

조작 바 맨 왼쪽 **큰 버튼 하나**(또는 `Space`)만 눌러도 처음부터 끝까지 진행됩니다.

## 단축키 (진행자 화면)

| 키 | 동작 |
|---|---|
| `Space` | 다음 단계 |
| `←` `→` | 이전 / 다음 문제 |
| `F` | 전체화면 켜기 / 끄기 |
| `Esc` | 전체화면 끄기 |
| `H` | 아래 조작 바 숨기기 / 보이기 |

## 사고 대비

- 진행자가 새로고침하거나 노트북을 바꿔도 답변·점수는 Firebase에 남습니다. 같은 진행자 주소로 다시 열면 이어집니다.
- 팀 휴대폰 화면이 꺼져도 같은 휴대폰으로 다시 들어오면 팀 선택과 점수가 그대로입니다.
- 연결이 끊기면 진행자 화면 오른쪽 위에 빨간 **«연결 끊김»** 이 뜹니다.
- 문제를 잘못 띄웠으면 **⋯ 더보기 → 이 문제 답 초기화**.
- **전체 초기화**는 답변·점수·접속한 팀 목록을 모두 지웁니다. 리허설 후 실전 전에 한 번 누르세요.
- 행사 직전 실제 휴대폰으로 QR을 찍어 접속을 확인하세요.
